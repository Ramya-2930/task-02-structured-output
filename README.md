# Task 02 - Structured Output

## Project Overview

This project demonstrates structured JSON output
generation, schema validation, and retry handling.

## Objectives

- Generate structured JSON data.
- Validate output using a JSON schema.
- Reject invalid output.
- Retry when validation fails.
- Return valid data after successful validation.

## Technologies Used

- Python
- JSON
- JSON Schema

## Features

1. Predefined JSON schema.
2. Data type and required field validation.
3. Invalid output rejection.
4. Retry mechanism.
5. Formatted JSON output.

## Installation

Install the required package:

```bash
python -m pip install -r requirements.txt
```
